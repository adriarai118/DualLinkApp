# دانلودر دولینکه (DualLink Downloader)

اپ اندروید که یک فایل را **هم‌زمان از وای‌فای و داده همراه** دانلود می‌کند و سرعت دو لینک را با هم جمع می‌کند.
بدون VPN، بدون سرور واسط، بدون روت. هیچ کتابخانه خارجی ندارد (فقط Android + Kotlin).

## حالت کل گوشی (VPN)
با روشن کردن این حالت، اپ یک VPN محلی می‌سازد (بدون سرور بیرونی). همه ترافیک گوشی از موتور
[hev-socks5-tunnel](https://github.com/heiher/hev-socks5-tunnel) رد می‌شود و هر اتصال TCP یا جریان UDP
جداگانه روی وای‌فای یا دیتا فرستاده می‌شود؛ لینک سریع‌تر اتصال‌های بیشتری می‌گیرد. DNS هم از همان لینکی می‌رود که اتصال از آن می‌رود.

- برنامه‌هایی که چند اتصال هم‌زمان دارند (مرورگر، آپدیت چند برنامه، دانلود منیجرها، اینستاگرام) سریع‌تر می‌شوند.
- یک اتصال تکی همیشه فقط از یک لینک می‌رود (بدون سرور واسط راهی برای شکستنش نیست).
- «حالت سازگار»: همه اتصال‌های یک سایت از یک لینک می‌روند؛ برای بانک‌ها یا سایت‌هایی که با عوض شدن IP از حساب خارج می‌کنند.
- هم‌زمان با VPN دیگری کار نمی‌کند (محدودیت اندروید).
- برای روشن ماندن دائمی: تنظیمات ← شبکه ← VPN ← DualLink ← Always-on.

## چطور کار می‌کند (دانلودر)
1. با `ConnectivityManager.requestNetwork` از اندروید می‌خواهد داده همراه را **کنار وای‌فای روشن نگه دارد** (در حالت عادی اندروید با وصل شدن وای‌فای دیتا را کنار می‌گذارد).
2. فایل به تکه‌ها تقسیم می‌شود. روی هر لینک چند اتصال هم‌زمان (پیش‌فرض ۴) باز می‌شود و هر اتصال با درخواست HTTP `Range` تکه بعدی را می‌گیرد — هر اتصال از طریق `Network.openConnection` به یک شبکه مشخص بسته شده است.
3. لینک سریع‌تر خودبه‌خود تکه‌های بیشتری برمی‌دارد. وقتی تکه‌ها تمام شد، اتصال بیکار نیمه دوم بزرگ‌ترین تکه نیمه‌کاره را «می‌دزدد» تا لینک کند انتهای دانلود را معطل نکند.
4. اگر یک لینک قطع شود، تکه‌هایش به صف برمی‌گردد و لینک دیگر ادامه می‌دهد (تا ۶۰ ثانیه هم منتظر برگشتن لینک می‌ماند).
5. فایل نهایی در اندروید ۱۰ به بالا در `Download/DualLink` ذخیره می‌شود؛ در نسخه‌های قدیمی‌تر در پوشه اپ (`Android/data/com.duallink.downloader/files/Download`).

## ساخت APK

### روش ۱ — GitHub Actions (بدون نصب چیزی)
1. یک ریپوی (می‌تواند Private باشد) در GitHub بسازید و کل این پوشه را push کنید.
2. در تب **Actions**، اجرای «Build APK» خودکار شروع می‌شود (حدود ۳–۵ دقیقه).
3. از صفحه همان اجرا، بخش **Artifacts** فایل `DualLink-debug-apk` را دانلود کنید؛ داخل zip فایل APK است.

### روش ۲ — Android Studio
پوشه را با **Open** باز کنید، صبر کنید Gradle Sync تمام شود، بعد `Build > Build App Bundle(s) / APK(s) > Build APK(s)`.
یا در ترمینال: `./gradlew assembleDebug` ← خروجی در `app/build/outputs/apk/debug/app-debug.apk`

نیازها: JDK 17، Android SDK 34 (Android Studio خودش نصب می‌کند).

## استفاده
- وای‌فای و دیتا هر دو باید روشن باشند (دیتا را از پنل بالای گوشی روشن کنید؛ اپ خودش آن را کنار وای‌فای فعال نگه می‌دارد).
- لینک را بچسبانید، یا از مرورگر/تلگرام/بله لینک را **Share** کنید به همین اپ.
- «اتصال هم‌زمان روی هر لینک» (۱ تا ۳۲): ۴ تا ۸ معمولاً کافی است؛ عدد بالاتر روی سرورهایی که سرعت هر اتصال را محدود می‌کنند کمک می‌کند. اگر سرور خطای ۴۲۹/۵۰۳ داد کمش کنید.
- بخش «لینک‌ها» سرعت و سهم هر شبکه را زنده نشان می‌دهد.

## محدودیت‌ها (مهم)
- **فقط برای دانلود فایل** است، نه کل اینترنت گوشی (مرورگر، اینستاگرام، تماس تصویری و… سریع‌تر نمی‌شوند). برای آن حالت سرور واسط (VPS) لازم است.
- سرور باید **Range** را پشتیبانی کند (اکثر سایت‌های دانلود و CDNها می‌کنند). اگر نکند، اپ خودکار فقط با یک لینک دانلود می‌کند و پیام می‌دهد.
- اتصال‌های این اپ **از VPN عبور نمی‌کنند** (شبکه‌های مستقیم استفاده می‌شوند). پس لینک‌هایی که فقط با VPN باز می‌شوند دانلود نمی‌شوند.
- لینک‌هایی که به کوکی/لاگین مرورگر وابسته‌اند (بعضی لینک‌های موقت) ممکن است کار نکنند.
- ادامه دانلود قطع‌شده (Resume بعد از بستن اپ) فعلاً پشتیبانی نمی‌شود.
- حجم دیتای مصرفی از بسته اینترنت سیم‌کارت کم می‌شود.
- روی بعضی گوشی‌ها (شیائومی/هواوی) اگر دانلود در پس‌زمینه متوقف شد، «Battery saver» را برای اپ روی No restrictions بگذارید.
